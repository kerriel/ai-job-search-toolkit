# Applications Tracker

This is the format for your applications tracker. How you keep it depends on how you use the toolkit:

- in Claude Code, Claude creates `applications.md` in your project folder the first time you apply for a role, and keeps it up to date
- in Claude in the browser or desktop app, you don't need the file, because Claude keeps your application history in its memory
- in another AI assistant, it gives you the tracker in a grey box to save yourself, as the [guide for any AI assistant](../setup-any-ai-assistant.md) explains

Copy the words you need and change the words in square brackets.

1. **To log an application:**
   ```
   I've applied for the [job title] role at [company].
   ```
2. **When something changes:**
   ```
   I've got an interview for the [job title] role at [company]. Update my tracker.
   ```
3. **To see your history:**
   ```
   Which roles have I applied for, and where is each one up to?
   ```
4. **To see the tracker in Claude Code:**
   ```
   Show me my applications tracker.
   ```

### What each status means

Claude uses one of these in the Status column:

- **Applied:** application submitted
- **Phone screen:** initial call scheduled or completed
- **Interview:** progressed to interview stage
- **Offer:** offer received
- **Rejected:** application unsuccessful
- **Withdrawn:** you withdrew from the process

### What goes in Posted By

Use "Direct" for roles posted by the employer. For recruiter-sourced roles, note the recruiter name and agency (for example, "Jane Smith, Hays").
